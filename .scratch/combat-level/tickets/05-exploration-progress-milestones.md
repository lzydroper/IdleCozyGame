# 05 — 探索进度与里程碑

**What to build:** 探索完成事件为该区域累计进度；区域 explorationStepsToClear 定义 100%。里程碑为一次性节点：累计进度首次越过阈值且本次探索已完成步数 ≥ 全局 minRunSteps（7）时触发；触发后该区域进度暂停，直到里程碑完成。战斗型里程碑不可撤离、胜利完成、失败终止探索并保留待办；选择型里程碑做出选择即完成。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] regionProgress 按完成事件累计；百分比 = min(100, steps / explorationStepsToClear × 100)。
- [ ] 里程碑按 atPercent 升序一次性触发；触发条件同时满足累计阈值与本次探索步数 ≥ minRunSteps。
- [ ] 存在待办里程碑时，该区域进度不再累加；完成后恢复累计。
- [ ] 战斗型里程碑不可撤离：胜利清除待办，失败终止探索并保留待办；选择型里程碑任意选择即清除待办。
