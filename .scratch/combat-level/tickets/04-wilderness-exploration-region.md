# 04 — 荒野探索区域化（选区域 / 事件池 / 初始消耗）

**What to build:** 手动探索改为先选择区域：出发消耗由该区域 initialCost 决定，事件只从该区域事件池抽取（沿用现有类别权重），遭遇战事件继续进入统一战斗场景。救援仍按固定目标特殊触发，不进入普通事件池。事件池为空的区域不可探索。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 开始探索前必须选择区域；普通探索消耗读区域 initialCost，救援消耗保持独立。
- [ ] 事件抽取只在该区域 explorationEvents 内按类别权重进行；encounter 事件作为池中一员触发。
- [ ] 救援事件仍按救援目标特殊触发，不从区域池抽取。
- [ ] 空事件池区域在界面禁用并在开始前校验报错。
- [ ] 相关状态与组件测试更新并通过。
