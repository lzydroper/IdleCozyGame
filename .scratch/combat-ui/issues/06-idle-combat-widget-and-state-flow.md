# 06 — 挂机战斗简略信息看板（IdleCombatWidget）交互与流转

Type: grilling
Status: resolved
Blocked by: 03

## Question

挂机战斗开启后，战斗子页面如何切换为挂机监控看板？需决议：

1. **页面状态自动切换**：
   - 玩家在关卡详情中点击【挂机战斗】后，「战斗」子页面自动切换为「挂机监控中」状态；
   - 关卡选择区折叠或置于次级，主区域展示挂机看板。
2. **挂机看板信息要素**：
   - 当前挂机地点：`[区域名 · 关卡名]`；
   - 挂机状态统计：已挂机时长、已完成战斗场次；
   - 实时体力监控条：当前体力 / 最大体力，以及体力消耗与自动恢复进度；
   - **简略战斗信息轮播区 (Ticker)**：实时滚动展示最新 3~5 条精简战斗事件（如：`14:20:05 [关卡02] 胜利！获得 废铁×2, 粗制皮革×1 (消耗体力 8)`）；
   - 累计收益汇总卡片：图标 + 数量展示本次挂机已获得的全部物资总和。
3. **停止挂机交互**：
   - 显著的【停止挂机】按钮，点击后停止挂机循环；
   - 弹出本次挂机战利品总览弹窗，并恢复关卡选择界面。
4. **全 JSON 兼容**：挂机状态持久化字段（`state.combat.idle`）纯数据化。

产出：`IdleCombatWidget` 组件规范与状态迁移流。

## Answer

（HITL grilling，精准落实三行事件流窗口与统一体力扣减语义）

- **D1 状态互斥切换**：处于挂机状态时，页面沉浸展示「挂机战斗监控看板」，隐藏关卡列表；未挂机时展示选关与挂机选定入口。
- **D2 三行高度可滚动的完整战斗事件流**：挂机简略信息区展示**完整的战斗事件流**（与全屏战斗同源的技能/伤害/Buff/阵亡事件），容器固定为约 3 行事件的高度，支持向上滑动回溯查看历史记录，模拟队伍持续实战的动态体验；具体视觉动效在 07 原型中调校。
- **D3 统一体力扣减时机（对齐 Offline.md）**：体力统一在每轮战斗**开始时**扣除，战斗结束后结算战利品；中途停止挂机不退还当前这轮已扣除的体力；体力耗尽自动停止。
- **D4 停止挂机与汇总弹窗**：点击【停止挂机】终止循环，弹出本次挂机战利品汇总清单（场次、时长、累计掉落），确认后平滑返回选关列表。
