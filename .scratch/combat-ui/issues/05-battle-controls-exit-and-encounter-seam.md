# 05 — 战斗页面控制与退出/撤离/跳过语义（Battle Controls & Exit Semantics）

Type: grilling
Status: resolved
Blocked by: 04

## Question

战斗页面内的退出/跳过控制与外部系统（如探索遭遇战）如何严格划分边界？需决议：

1. **退出按钮的范围与惩罚结算**：
   - 仅从「战斗」子页面发起的主动战斗在右上角显示【退出】按钮；
   - 点击后触发二次确认警告（“退出将视为战斗失败，小队全员将进入重伤状态，是否确认退出？”）；
   - 确认后立即中止战斗，按失败结算（扣除体力、小队英雄全员重伤、无战利品获得）。
2. **探索遭遇战（Encounter）的只读对接**：
   - 荒野探索中触发战斗遭遇卡牌时，点击“迎战”唤起战斗页面，传入 `isEncounter: true`；
   - 战斗页面内**严格隐藏【退出】按钮**（探索中的“撤离”已在探索卡片阶段处理，进入战斗后只读战斗结果）；
   - 战斗结束后直接将结算结果回调给探索系统（战利品进探索临时背包，若战败则结束探索并全员重伤）。
3. **播放控制与单次跳过 (ADR-0008 落地)**：
   - 速度控制：1x（标准速度）与 2x（加速播放）；
   - 【单次跳过 (Skip)】按钮：点击立即推进并完成整场战斗动画，直接弹出结算结果。

产出：战斗控制栏交互状态机与跨系统只读接入规范。

## Answer

（HITL grilling，确认预计算模型下的控制语义）

- **D1 保持预计算+假同步播放模型**：战前瞬时算完全场 `events[]`，UI 层按定时器平滑播放；全自动战斗无需战中手动选卡，切后台/断网不中断。
- **D2 退出按钮与失败惩罚**：仅在主动战斗页面提供右上角【退出】按钮，二次确认后按战斗失败结算（体力扣除、小队全员重伤、无战利品）。
- **D3 探索遭遇战只读对接**：探索遭遇战唤起战斗页面时传入 `isEncounter: true`，隐藏退出按钮，打完后原样将结果回传探索系统。
- **D4 播放控制与单次跳过**：提供 1x / 2x 倍速控制前端 `events` 播放间隔；单次跳过（Skip）直接拉满事件指针并瞬间弹出结算。
