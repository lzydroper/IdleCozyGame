# 04 — 荒野探索遭遇战只读对接

**What to build:**
将「荒野探索」抽卡流中触发的战斗遭遇事件与全屏 `BattleModal` 无缝对接。当玩家在荒野探索中遭遇战斗时，唤起 `BattleModal` 并传入只读标识（`isEncounter: true`）。在遭遇战场景下，右上角【退出】按钮严格隐藏（撤退与逃跑在探索卡片阶段已完成）；战斗结束（胜利或失败）后，将战果与小队伤势状态无缝回传给荒野探索流程，继续推进探索结算。

**Blocked by:** 03 — 独立全屏战斗场景模态（6 竖槽战场 + 动效 + 调速/跳过/退出）

**Status:** ready-for-agent

## Acceptance Criteria

- [ ] 荒野探索卡片抽到敌方遭遇战时，唤起全屏 `BattleModal` 场景。
- [ ] 遭遇战模态中，右上角【退出】按钮严格隐藏不渲染。
- [ ] 战斗过程中支持正常使用 `1x`/`2x` 调速与 `跳过` 功能。
- [ ] 战斗胜利：小队继续探索流程，掉落物计入探索背包。
- [ ] 战斗失败：探索终止，小队全员进入重伤状态，返回荒野主界面。
- [ ] 提供完整的 Vitest 自动化单元测试（验证遭遇战唤起、退出按钮隐藏、胜负状态回传探索系统）。
