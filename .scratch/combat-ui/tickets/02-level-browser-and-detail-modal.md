# 02 — 关卡方块网格与关卡详情弹窗

**What to build:**
在「战斗」Tab 中以物品方块网格形式渲染所选区域的全部关卡（`LevelBrowser`）。支持「挑战」与「挂机」两种模式切换：两个模式均展示该区域所有关卡。挑战模式标示已通关/可挑战/未解锁；挂机模式标示可挂机/未解锁。点击关卡唤起 `LevelDetailModal` 弹窗，展示体力消耗、敌方阵容（带 `[首领]` 标识）、可能掉落池。若处于待解锁区域或在挂机模式下点击未通关关卡，弹窗内弹出诊断提示框，底部的【确认】按钮置灰禁用（文案严格保持为【确认】）。

**Blocked by:** 01 — 子 Tab 导航架构与通用区域选择器组件

**Status:** resolved

## Acceptance Criteria

- [x] 关卡列表采用紧凑小方块网格（Grid）展示，包含关卡序号（如 `01`）、关卡名称与精简状态标签。
- [x] 「挑战」与「挂机」模式开关平滑切换：
  - 挑战模式：关卡状态为 `已通关`、`可挑战` 或 `未解锁`；
  - 挂机模式：展示全部关卡，已通关关卡标示 `可挂机`，未通关关卡标示 `未解锁`。
- [x] 点击关卡打开 `LevelDetailModal`：
  - 展示体力消耗（如 `消耗体力: 10 点`）；
  - 敌方阵容正确展示，Boss 携带 `[首领]` 标签；
  - 展示首通奖励与掉落池。
- [x] 锁住诊断：若所选区域为待解锁区域，或在挂机模式下点击未通关关卡，弹窗顶部展示诊断提示，底部【确认】按钮置灰禁用（`disabled`）。
- [x] 按钮文案严格保持为【确认】与【取消】，杜绝文案动态篡改。
- [x] 提供完整的 Vitest 自动化单元测试（验证网格渲染、模式切换、详情弹窗与确认点击回调）。
