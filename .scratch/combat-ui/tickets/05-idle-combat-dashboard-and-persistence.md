# 05 — 挂机监控看板与收益汇总流转（`IdleCombatWidget`）

**What to build:**
在「挂机」模式下选定已通关关卡并点击【确认】后，启动挂机战斗循环，沉浸展示 `IdleCombatWidget` 监控看板。挂机中自动隐藏顶部的区域更换卡片与模式切换开关，杜绝状态冲突；看板中包含 3 行固定高度完整事件流窗口，持续平滑滚动推入战况；开战瞬间扣除对应体力，停止挂机不退还当前未完成战斗的体力；点击【停止挂机】弹出物资集中汇总弹窗（时长、场次、累计获得物品），确认关闭后保持在「挂机」模式；挂机状态持久化到 `state.combat.idle` 纯数据结构，彻底清理旧版无用字段。

**Blocked by:** 02 — 关卡方块网格与关卡详情弹窗, 03 — 独立全屏战斗场景模态（6 竖槽战场 + 动效 + 调速/跳过/退出）

**Status:** resolved

## Acceptance Criteria

- [x] 选定已通关关卡确认开启挂机后，切换展示 `IdleCombatWidget` 监控看板，关卡列表、区域更换条与模式开关安全隐藏。
- [x] 3 行固定高度事件流窗口：每完成一轮战斗，扣除体力并推入完整技能/击杀事件，支持向上滑动查阅历史记录。
- [x] 扣费规则：每一轮战斗开始时扣除体力；手动点击停止挂机时，当前进行中的最后一轮战斗体力不退还。
- [x] 体力耗尽时挂机自动停止并弹出提示。
- [x] 点击【停止挂机】弹出汇总弹窗，展示总时长、战斗场次与累计战利品；点击【确认】关闭弹窗，页面继续停留在「挂机」模式。
- [x] 状态持久化：`state.combat.idle` 仅包含纯数据字段（`{ regionId, levelId, startTime, lastTickTime, totalBattles, totalDrops }`），彻底移除旧版 `combat.currentZoneId` 等废弃字段。
- [x] 提供完整的 Vitest 自动化单元测试（验证挂机开启、事件流滚动、停止汇总弹窗、体力扣除与存档纯数据序列化）。
