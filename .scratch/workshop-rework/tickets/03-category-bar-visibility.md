# 03 — 分类栏位与配方可见性

**What to build:** 工坊引入 5 类分类栏（道具/资源/碎片/装备/建筑，对齐背包产出物类别 + 补充「建筑」类），无「全部」入口、空分类显示空态、计数基于可见配方；配方可见性规则生效——蓝图锁定（未获得图纸）与已达上限（温室扩建）的配方从列表隐藏，材料不足的配方仍可见但不可合成。

**Blocked by:** 02 — 补给面板删除与工坊组件拆分

**Status:** ready-for-agent

- [ ] 分类栏显示 5 类并可切换过滤；分类定义来自配置（id/标签/图标/排序），可扩展
- [ ] 空分类（含碎片分类）显示空态提示，判定基于可见配方
- [ ] 未获得图纸的配方不在列表出现，无"未解锁/锁图标/需要图纸"展示
- [ ] 材料不足的配方可见但不可合成；温室扩建已达上限后该配方隐藏
- [ ] 组件测试覆盖分类切换、空态、可见性过滤
