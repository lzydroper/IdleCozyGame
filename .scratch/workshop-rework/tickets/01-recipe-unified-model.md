# 01 — 配方数据模型统一

**What to build:** 手动与自动配方共享统一的类型定义与字段命名（cost/reward），5 对数值完全一致的重复配方去重（仅保留工坊侧条目、删除自动侧重复，旧存档中被删自动 id 自动迁移映射不丢队列），配方显示名/描述从产出物完全推导。设施自动生产、离线结算日志、工坊与设施列表均基于新模型正常工作。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 手动/自动配方使用同一共享类型；字段统一为 cost/reward；name/description 字段移除，改由推导辅助提供
- [ ] 5 对完全一致的重复配方仅保留工坊侧条目，3 对近似配方（数值有刻意差异）双条目保留
- [ ] 工坊与设施列表显示推导文案（「合成 {产物名} ×N」），描述来自物品注册表；无产物配方兜底正确（胶囊充能 → 稳定胶囊；温室扩建 → 显式显示名）
- [ ] 设施队列状态层与设施卡片组件迁移到新字段命名，自动生产/队列/日志无回归
- [ ] 加载含已删自动 id 的旧存档：迁移映射使旧 id 走正常校验路径（不触发未知 id 异常），映射目标为工坊侧手动配方、不在自动表，旧队列条目按配置变更防御逻辑清出；保留配方与设施 id 防呆校验不受影响
- [ ] 状态层/迁移相关测试通过（含现有合成与存档合并测试更新）
