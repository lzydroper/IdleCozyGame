# 05 — 战斗内面板重算 seam

**What to build:** 运行时战斗单位保留入场原始属性配方与常驻修正符；战斗上下文提供按当前修正符重算面板的入口。能力计算来源侧数值前读取重算后的当前面板；入场静态面板仅用于展示与兜底。

**Blocked by:** 01 — Ability 类型与配置注册表

**Status:** ready-for-agent

- [ ] 运行时单位携带可重算的原始属性配方与常驻修正符。
- [ ] 战斗上下文能基于原始配方 + 常驻修正符 + 战斗内动态修正符重算当前面板。
- [ ] 能力取数前可拿到重算后的当前面板。
- [ ] 静态入场面板与当前面板职责区分，不互相污染。
- [ ] 测试覆盖属性增益/减益后重算结果与静态面板保持不变。
