# 01 — Ability 类型与配置注册表

**What to build:** 定义能力系统的类型契约（能力配置、运行时能力实例、目标策略、公式模板、效果模板、被动声明），并建立数据驱动的能力注册表，收录普通攻击与现有觉醒技能；提供「配置 → 运行时能力实例」的纯函数解析。本票只打地基，不接入战斗执行。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 能力配置类型与运行时实例类型齐备，且可互相解析。
- [ ] 普通攻击作为显式配置存在：无消耗、无冷却、优先级最低、目标为单个敌方单位。
- [ ] 现有觉醒技能全部迁入注册表，保留原有效果类型与数值语义（单体重击 / 群体攻击 / 自身治疗）。
- [ ] 配置解析为运行时实例是纯函数：同一配置输入，输出逐字段确定一致。
- [ ] 测试覆盖所有已迁移技能的解析结果与往返一致性。
