# 02 — 目标选择器

**What to build:** 实现纯函数目标选择器：根据目标策略，从当前存活单位中选出目标列表。支持单个敌方、全体敌方、最低生命敌方、自身、最低生命百分比友方、全体友方六种策略；单目标敌方选择受嘲讽标记覆盖；无有效目标时返回空列表。

**Blocked by:** 01 — Ability 类型与配置注册表

**Status:** ready-for-agent

- [ ] 六种目标策略均返回正确的目标集合。
- [ ] 单目标敌方策略在存在嘲讽标记时改选嘲讽标记最高的敌方单位；同值按入场序。
- [ ] 全体敌方策略不受嘲讽覆盖。
- [ ] 选择器为纯函数，同输入同结果；无有效目标返回空列表。
- [ ] 测试覆盖六种策略、嘲讽覆盖、同值排序与空目标。
