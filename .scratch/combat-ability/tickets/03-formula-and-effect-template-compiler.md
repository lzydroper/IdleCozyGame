# 03 — 公式与效果模板编译器

**What to build:** 把固定公式模板求值为来源侧最终数值，并把效果模板展开为一个或多个效果实例。多目标按目标列表拆成单目标效果；需要挂 Buff 的模板先生成 Buff 实例；放大倍数写入触发上下文供 Buff 触发消费。

**Blocked by:** 01 — Ability 类型与配置注册表

**Status:** ready-for-agent

- [ ] 固定公式模板可求值：攻击倍率、最大生命百分比、固定值。
- [ ] 效果模板可展开为效果实例，参数正确引用公式输出或常量。
- [ ] 多目标效果按目标拆分为单目标效果，每个目标一条。
- [ ] 挂 Buff 模板在派发前构造好 Buff 实例。
- [ ] 放大倍数默认 1，并写入触发上下文。
- [ ] 测试覆盖公式求值、多目标拆分、挂 Buff 构造与放大倍数传递。
