# Melvor 式改造（Melvor-Rework）— Spec

将 AetherGarden 从放置经营改造为 Melvor Idle 式深度养成游戏：英雄召唤、自动战斗、多维度养成、产线队列。本文档是 ticket 集的总览；领域术语见根目录 `CONTEXT.md`，架构决策见 `docs/adr/0001-0006`。

## 上游决策（ADR）

- **0001** 英雄获取：统一召唤池 + 救援免费共存 + 无稀有度 + 软保底 + 初始英雄诺娃
- **0002** 战斗模型：三人轮询回合制 + 探索战斗汇合 + 确认式离线挂机 + 线性区域/BOSS + 羁绊/阵营
- **0003** 英雄养成：战斗经验 + 3槽系列套装/神话锻造 + 3职阶天赋树 + 升星/觉醒
- **0004** 产线：FIFO 配方队列 + 等级扩容 + 纯自动
- **0005** 退役旧 passives，差异化交予新系统
- **0006** 废除全局 HP：重伤/梦境封锁/炮塔辅助/探索惩罚移除
