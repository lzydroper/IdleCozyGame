# 05 — 战斗核心：三人轮询回合制

**What to build:** 自动战斗循环：选择战斗区域后三人小队（当前上阵队伍）按轮询回合制自动战斗，无阵型；消耗独立"体力"（随时间恢复）；胜利获得材料与经验掉落；战斗失败 → 小队全员进入"重伤"状态（禁止上阵），需使用改造后的纳米修复剂治愈。战斗场景是探索战斗汇合与离线挂机共同的基础。

**Blocked by:** 02 — 英雄实体与初始英雄.

**Status:** ready-for-agent

- [ ] 选择测试区域后小队自动轮询战斗，回合按固定顺序轮流行动
- [ ] 战斗消耗体力（随时间恢复），体力不足无法开战
- [ ] 胜利掉落材料与经验，失败后小队全员重伤（禁止上阵）
- [ ] 纳米修复剂可治愈重伤英雄，治愈后恢复上阵
- [ ] 战斗结果（掉落/经验/重伤）入账并有测试覆盖
