# 11 — 职阶天赋树

**What to build:** 升级获得天赋点，投入职阶天赋树：职阶（守护者/进攻者/协奏者）公共主干 + 每英雄专属节点，各英雄天赋树独立。加点效果生效于战斗属性。

**Blocked by:** 05 — 战斗核心：三人轮询回合制.

**Status:** resolved

- [x] 英雄升级获得天赋点（经验来自战斗）
- [x] 天赋树按职阶组织公共主干，英雄各有专属节点
- [x] 加点界面可分配/重置，效果计入战斗数值
- [x] 天赋树配置数据驱动，至少 3 职阶各 1 棵可加点

## Answer

实现于 commit `feat: 职阶天赋树（ticket 11）`，落地方式：

- **数据驱动**：`src/data/talents.ts` 定义 3 棵职阶公共主干（守护者/进攻者/协奏者，各 3 节点顺序递进）+ 9 位英雄专属节点（挂载在对应职阶主干入口之后），节点效果为每级百分比战斗加成（`CombatBonus`）。
- **天赋点**：`combat.ts` 的 `applyHeroExp` 每次升级 +1 天赋点（多级连升按级数累计），经验仅来自战斗；`HeroState` 新增 `talentPoints`（未分配）与 `talents`（节点投入）。
- **加点纯函数**：`src/state/talents.ts` 提供加点（消耗 1 点、前置锁定、满级上限）、撤点（返还 1 点、下游已投入时拒绝以保持树形完整）、重置（全部返还）与加成汇总（每级效果 × 投入点数线性叠加）。
- **战斗生效**：`heroToCombatant` 将天赋百分比与羁绊/装备百分比叠加（生命按新上限同比例缩放），自动战斗/探索遭遇/BOSS 战/离线挂机统一接入。
- **UI**：英雄页新增天赋面板 —— 职阶主干/英雄专属分组、+/− 加点按钮（锁定/满级/点数不足禁用态）、等级星标、重置按钮与当前加成摘要。
- **迁移**：`mergeSavedState` 为旧存档补默认值，逐节点钳制等级至配置上限并丢弃未知/非法节点（防损坏存档撑爆 UI 与加成）。
- **测试**：`src/state/talents.test.ts` 19 例（配置完整性、升级加点、加点/撤点/重置与守卫、加成计算、战斗集成、存档迁移）+ 组件测试 2 例，全套 205 例通过。
