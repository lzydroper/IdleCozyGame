# 09 — 羁绊与阵营加成

**What to build:** 队伍构筑策略层：羁绊表（特定英雄组合同时上阵触发额外数值加成）+ 六阵营（奥术/机械/梦魇/英灵/星界/魂印）驱动。上阵 3 人小队中满足羁绊组合即触发加成，生效于战斗数值。

**Blocked by:** 02 — 英雄实体与初始英雄; 05 — 战斗核心：三人轮询回合制.

**Status:** resolved

- [x] 羁绊表数据驱动配置，标注触发组合与加成数值
- [x] 上阵队伍满足羁绊组合时，加成在战斗中生效并可见
- [x] 英雄阵营字段参与羁绊/加成判定
- [x] 至少 2 组示例羁绊落地，有测试覆盖触发与失效

## Answer

实现于 commit `feat: 羁绊与阵营加成（ticket 09）`，落地方式：

- **数据驱动**：`src/data/bonds.ts` 新增 `CombatBonus`（攻击/防御/生命百分比）、`BondConfig`（`heroes` 英雄组合 + `factions` 阵营数量双条件）与 3 组示例羁绊（机械搭档 nova+roy 攻击+10%、奥术共鸣 arcane×2 生命+10%、废土守护 buster+soldier 防御+10%）。
- **判定纯函数**：`src/state/bonds.ts` 的 `getActiveBonds(party)`（英雄全上阵 + 各阵营人数 ≥ N，未知英雄防御性忽略）与 `aggregateBonus(party)`（百分比求和）。
- **战斗中生效**：`combat.ts` 的 `heroToCombatant` 接受加成并按比例放大攻击/防御/生命（当前血量同比例缩放），普通战斗/探索遭遇/BOSS 战/离线挂机四条路径统一接入；战斗为独立场景，结算写回英雄状态时不泄漏加成。
- **可见**：英雄页上阵队伍区与荒野页战斗面板展示激活羁绊（名称 + 加成数值 + 触发说明 tooltip），未触发时给出提示。
- **测试**：`src/state/bonds.test.ts` 16 例（配置完整性、触发/失效、阵营判定、战斗伤害/存活差异、BOSS 路径端到端）+ 组件测试 3 例。
