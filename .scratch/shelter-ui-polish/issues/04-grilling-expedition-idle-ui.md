## Answer

### 1. 未派遣状态卡片结构（按原型）

- 标题栏右侧「派遣」按钮（cyan 主题色带背景边框）→ 打开 DutyAssignModal 选探索员（复用 T02）。
- 已选探索员后：标题栏显示「探索员：XXX」+「更换」按钮（用户决策：选后显示+更换按钮），点击「更换」重新打开弹窗。
- 卡片主体：探索员信息（头像/名称/职阶·阵营）+ 地点卡片列表。

### 2. 探索员选择交互（用户决策）

- **未选**：标题栏右侧「派遣」按钮（`bg-cyan-500/10 text-cyan-400 border-cyan-500/30`）→ DutyAssignModal。
- **已选**：标题栏右侧「更换」按钮（同款 cyan 样式），subtitle 显示「探索员：{name} [职阶 · 阵营]」。
- 选择状态：`selectedExpExplorerId` state 保留。

### 3. 地点卡片式选择

- 保持现有地点卡片列表（`:809-858`），移除「步骤2」标签。
- 卡片展示优化：地点名 + 门槛徽章（需【职阶/阵营】）+ 拾荒间隔 + 可能拾得（物品名）+ 口粮消耗（`rationCost`）。
- 点击选中高亮（现有逻辑 `:821-823` 保留）。
- 门槛不匹配时显示警告（现有 `requirementUnmatch` 逻辑保留）。

### 4. 口粮消耗提示（原步骤3）

- 保留为卡片底部信息块（现有 `:862-876`），移除「步骤3」标签。
- 显示：当前持有口粮 / 需消耗（`rationCost`）/ 充足或不足状态。

### 5. 开始派遣按钮

- 保留为卡片底部「开始挂机远征派遣」按钮（现有 `:878-903`）。
- disabled 逻辑不变：未选探索员 / 门槛不匹配 / 口粮不足。

### 6. 已派遣状态微调：召回按钮移标题栏（用户决策）

- 已派遣状态（`:712-776`）按原型微调：
  - 标题栏右侧「召回」按钮（红色 `bg-rose-500/10 text-rose-400 border-rose-500/30`）代替底部全宽按钮。
  - 卡片主体保留：探索员信息 + 已累积时间 + 距下次拾荒 + 战利品表。
  - 移除底部全宽「一键召回 / 结算远征收益」按钮（`F776-776` 区域）。

### 领域术语更新

- **远征派遣状态 (Expedition Dispatch State)**：未派遣（选探索员+选地点+派遣）/ 已派遣（进行中+召回）。交互统一：操作按钮在标题栏右侧。
