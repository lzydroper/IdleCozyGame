# 08 — 产线 UI 改造（变体 B）

**What to build:** 产线 tab 从"队列管理"改为"任务管理"（变体 B，源自 03 决议与原型）：设备卡只做状态摘要——待机态显示设备名/等级/**驻守按钮**（保留现有指派弹窗入口与加成摘要）/「＋ 生产」按钮；生产中态显示配方名、当前批进度条、"已产 X / 目标 N 批"、当前批剩余、总剩余时间、「取消任务」。点「生产」弹滑条弹窗（配方选择 + 批次滑条，上限 = 当前材料可支撑批次数，含消耗/产出预览与每批产出加成）；点「取消」弹确认弹窗并预览退款（"已产出的 X 批将保留，将退还：材料 ×Y"）。移除产线 tab 的队列区（入队下拉、队列列表、启停开关）。

**Blocked by:** 06 — 单任务状态机、07 — 在线 + 离线推进接线

**Status:** ready-for-agent

- [ ] 设备卡待机态：设备名/等级/驻守按钮（打开现有指派弹窗，显示当前驻守英雄与加成摘要）/「＋ 生产」按钮
- [ ] 设备卡生产中态：配方名、当前批进度条、"已产 X / 目标 N 批"、当前批剩余、总剩余、「取消任务」
- [ ] 「生产」弹窗：配方选择 + 批次滑条（上限 = floor(材料 / 每批折扣成本)，材料不足上限为 0 且禁用）+ 消耗 ×N / 产出 ×N 预览（每批产出含驻守加成）+「开始生产（扣除全部材料）」；成功/失败有 toast 与日志
- [ ] 「取消」确认弹窗：退款预览（已产出保留、退还材料 ×Y）+ 确认/取消
- [ ] 多台设备各一张独立卡，任务各自独立；扩建后的新设备卡自动出现
- [ ] 产线 tab 移除队列区（入队/队列列表/启停）；基建 tab 升级/扩建卡不受影响（数据源已由 05 泛化）
- [ ] 测试：`FacilityCard` / `ShelterTab` 组件测试——待机/生产中渲染、生产弹窗滑条上限与预览、取消退款预览、驻守按钮保留可打开指派弹窗
- [ ] 手动验收：完整走通"选配方 → 滑条定批次 → 开始（扣全部材料）→ 进度推进 → 取消（退款预览）"；离线回归后任务续跑
