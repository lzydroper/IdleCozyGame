# 06 — 单任务状态机（纯函数层）

**What to build:** 产线从 FIFO 队列改为单任务批量生产。每台设备同时只跑一个「配方 × 批次」任务：玩家开始任务即扣除全部材料（含驻守成本减免），逐批产出入账，完成自动回到待机；取消任务退还已产出之外的全部材料（未开始 + 进行中批次按折扣单价全额退）。删除入队/移除/启停相关逻辑。本票为纯函数状态机 + 状态字段改造，UI 与 tick/离线接线由后续票完成。

**Blocked by:** 05 — 数据驱动设备注册

**Status:** ready-for-agent

- [ ] `AutomationFacility` 移除队列字段与启停开关，改为单任务字段（配方 id / 目标批次数 / 已完成批次数 / 当前批剩余秒 / 当前批进度），字段形状见 spec 的 Implementation Decisions（源自 01 决议）
- [ ] 开始任务：校验 `目标批次数 × 每批折扣成本` 足够 → 扣全部材料（原料减免折扣）→ 置任务；材料不足 / 已在生产中 / 未知配方拒绝且不扣料
- [ ] 推进：每完成一批 `已完成 +1` 并入账该批产出（产量加成 `floor(reward × (1 + yield))`）；达到目标批数自动回待机
- [ ] 取消任务：退款 = `(目标批数 − 已完成) × 每批折扣成本`（未开始 + 进行中批次全额退）；已产出保留；退款不赚差价（扣/退同价）
- [ ] 批次耗时按设备等级 + 驻守速度加成计算（沿用现有公式）
- [ ] 删除"队首材料不足自动暂停"逻辑与入队/移除/启停纯函数
- [ ] 旧存档队列字段一次性清空、加载无异常（新字段默认待机）
- [ ] 测试：`facility.test.ts` 队列测试替换为任务测试并全绿（开始扣料、逐批推进、完成判定、取消退款、单任务互斥、多台并行、加成计算）
