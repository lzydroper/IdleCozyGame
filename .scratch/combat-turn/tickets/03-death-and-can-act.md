# 03 — 死亡与无法行动判定

**What to build:** 死亡判定与可行动性：取出队首单位时读当前存活状态（非入场快照）判死亡，阵亡跳过其后所有主时机、只派一次死亡事件；Turn 只提供 canAct 谓词（由 Buff 状态汇总、不硬编码枚举），无法行动只跳过回合进行中、回合开始前/结束后仍结算，canAct 判定一次、本回合不变。

**Blocked by:** 01 — 先机回合核心引擎（tracer）；02 — 主时机与订阅接口

**Status:** ready-for-agent

- [ ] 取出队首单位时按当前状态判死亡（死单位不预过滤出队）。
- [ ] 阵亡单位跳过其后所有主时机，只派发一次死亡事件。
- [ ] 死于自己行动中（反伤致死）不结算其回合结束后。
- [ ] 复活语义：单位在轮到前被复活（hp>0）则正常行动。
- [ ] canAct 谓词由外部状态汇总，Turn 不硬编码眩晕等枚举。
- [ ] 无法行动只跳过回合进行中；回合开始前（含控制衰减/判定）与回合结束后仍结算。
- [ ] canAct 在回合开始前结算后判定一次、本回合内保持不变；判定顺序先死亡后 canAct。
- [ ] 测试：阵亡跳过、反伤致死、复活、眩晕只跳行动、canAct 一次性。
