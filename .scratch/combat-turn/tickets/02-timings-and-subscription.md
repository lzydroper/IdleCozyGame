# 02 — 主时机与订阅接口

**What to build:** 在核心循环接入五个轮次主时机（轮次开始前 / 回合开始前 / 回合进行中 / 回合结束后 / 轮次结束后）的结算，并提供时机/事件订阅表：订阅键 `(时机/事件 key, 单位 id | 全局)`、register/unregister、FIFO 固定顺序、同时机内新注册延后到下次结算、触发上下文（key / 归属单位 / 来源 / 目标 / 运行时只读引用）。

**Blocked by:** 01 — 先机回合核心引擎（tracer）

**Status:** ready-for-agent

- [x] 五个主时机在正确时点结算：轮次开始前（轮次边界）、回合开始前（取队首存活后）、回合进行中（行动）、回合结束后（行动后）、轮次结束后（轮次边界）。
- [x] 订阅键 = (时机/事件 key, 单位 id | 全局)；轮次级时机全局订阅、单位级时机按单位订阅。
- [x] register/unregister 正确；战斗结束订阅表整体清空（每场独立实例）。
- [x] 同一时机多个订阅者按 FIFO（注册序）触发，固定不可配置。
- [x] 同时机内新注册到同一时机的订阅延后到下一次结算，本轮迭代不触发。
- [x] 触发上下文至少含 时机/事件 key、归属单位、来源、目标、战斗运行时引用（只读）。
- [x] 测试：时机触发顺序、注册/注销、FIFO、延后再注册、上下文字段。
