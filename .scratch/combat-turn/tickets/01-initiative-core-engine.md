# 01 — 先机回合核心引擎（tracer）

**What to build:** 纯确定性回合引擎的端到端最小切片：定义战斗单位快照（id/name/faction/hp/maxHp/initiative/abilities/stats），先机计算为纯函数，按「先机降序、入场序升序」严格全序排序，驱动单队列 + 轮次分隔标记的轮次循环，直到一方全灭或超限平局，输出 `{ 结局, 事件流 }`。本切片只支持「纯普通攻击」（每次行动对目标造成固定伤害并记录事件），时机/召唤/控制/强制结束留后续票。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] 战斗单位快照类型落地；先机计算为纯函数（agility 公式 + clamp，上限 300）。
- [x] 排序键 = (先机 降序, 入场序 升序)；入场序全局单调（英雄上阵序 → 敌人配置序 → 召唤序续号）；严格全序、无并列。
- [x] 单队列 + 轮次分隔标记：一轮内每个存活单位行动一次，未行动区清空后进入新一轮。
- [x] 终止条件：一方全灭 → victory/defeat；轮次上限（可配置，默认 60）超限双方存活 → draw。
- [x] 输出事件流，含轮次开始 / 回合开始 / 攻击 / 阵亡 / 轮次结束等基础事件。
- [x] 纯确定性：同输入同 rng 种子 → 逐字节一致的事件流；rng 以函数参数注入。
- [x] 测试：排序（先机/tie-breaker）、轮次边界、全灭/超限终止、确定性复现。
