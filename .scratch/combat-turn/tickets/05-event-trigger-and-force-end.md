# 05 — 事件触发与强制结束

**What to build:** 事件触发 API 与标准细粒度事件键（攻击后 / 受到伤害 / 受到治疗 / 死亡 / 召唤），以及强制结束标记通道：Turn 维护可选结束标记 + 结果（victory/defeat/draw），循环每轮检查、置位即终止。

**Blocked by:** 02 — 主时机与订阅接口

**Status:** ready-for-agent

- [x] 事件触发 API：订阅者可在行为/效果结算时派发细粒度事件。
- [x] 标准事件键定义：攻击后 / 受到伤害 / 受到治疗 / 死亡 / 召唤。
- [x] 攻击后事件在行动入口完成后派发。
- [x] 强制结束标记通道：外部可置位（含结果 victory/defeat/draw），循环下一轮检查即终止。
- [x] 终止条件封闭集合：一方全灭 / 超限平局 / 强制结束。
- [x] 测试：事件派发、攻击后、强制结束（三种结果）。
