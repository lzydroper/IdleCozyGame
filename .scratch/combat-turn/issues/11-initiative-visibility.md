# 11 — 先机调试可见性（决策）

**Type:** grilling
**Status:** resolved
**Blocked by:** None

## Question

开发者如何观察先机值（Turn.md 规定先机不对玩家暴露，但开发者应有渠道知道）？

1. **形式**：测试断言（纯函数，主要渠道）？战斗日志/debug 面板（可选）？两者都要？
2. **不进玩家 UI** 是否确认（玩家 UI 不显示先机数值）？
3. 若提供 debug 输出，其载体（console / 战斗信息流 / 独立 debug 开关）？

产出：先机调试可见性方案。

## Answer

（HITL grilling，用户全部确认推荐方案）

- **D1 调试形式**：测试断言为主（先机计算与排序是纯函数，可直接断言）；开发期可选在战斗信息事件流附带先机/入场序调试字段（dev 开关控制）。
- **D2 不进玩家 UI**：确认——先机只存在于引擎与测试/debug，不进任何玩家可见 UI。
- **D3 debug 载体**：不单独做 debug 面板；经「战斗信息事件流」在 dev 模式附带调试字段（或 console），生产构建默认关闭。
