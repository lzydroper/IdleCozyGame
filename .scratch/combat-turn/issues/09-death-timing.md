# 09 — 死亡时机结算规则（决策）

**Type:** grilling
**Status:** resolved
**Blocked by:** None

## Question

阵亡单位的时机结算规则如何精确化？

1. **阵亡后跳过**：已阵亡单位从待参战队列取出后，是否跳过其后所有轮次主时机（回合开始前 / 进行中 / 结束后均不结算）？
2. **死于自己行动中**：单位在自己回合进行中（如反伤致死）阵亡后，是否仍结算其「回合结束后」？
3. **尚未行动即阵亡**：本回合尚未行动就被他人击杀的单位，是否结算「回合开始前」？（推荐不结算，直接跳过）
4. **「回合结束后」条件**：是否统一为「仅存活单位结算回合结束后」？

产出：死亡与时机结算的精确规则（配合状态机图更新 Turn.md）。

## Answer

（HITL grilling，用户确认推荐，并修订 9.3）

- **D1 阵亡后跳过**：已阵亡单位跳过其后所有轮次主时机（回合开始前 / 进行中 / 结束后均不结算），只派发一次「死亡」事件。
- **D2 死于自己行动中**：不结算「回合结束后」——死亡即时终止该回合剩余时机；「阵亡触发」用「死亡」事件表达，不借用「回合结束后」。
- **D3 尚未行动即阵亡**（用户修订）：**正常从队列取出 → 判定当前死亡状态 → 若死亡则跳过**（不结算任何主时机）。判定读取「取出时刻」的当前状态（**非入场快照**），以尊重复活类技能——若在轮到前已被复活（hp>0），则正常行动。
- **D4 统一规则**：**存活是结算任何主时机的必要条件**，且「存活」在**取出队首单位时**按当前状态判定（死单位不预过滤出队，仍在队列中，取出时判）。
