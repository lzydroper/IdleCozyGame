# 01 — 回合系统词汇对齐（决策）

**Type:** grilling
**Status:** resolved
**Blocked by:** None

## Question

战斗回合系统的核心术语如何定名，并与 `CONTEXT.md` 现有词汇对齐？需决议：

1. **轮次 vs 回合**：`CONTEXT.md` 现仅有「轮询回合制 (Round-Robin Turn)」，新模型为先机驱动。是否定名：**轮次 (Round)** = 一次全员行动周期；**回合 (Turn)** = 单个单位的行动机会？英文 key 各是什么？
2. **时机 vs 事件**：`Turn.md` 已分「轮次主时机」（轮次开始前/回合开始前/回合进行中/回合结束后/轮次结束后）与「细粒度战斗事件」（攻击后/受到伤害/受到治疗/死亡/召唤）。这两个词的中英文名与归属关系是否维持？
3. **先机 (Initiative)**：中文名与英文 key 确认（Turn.md 已给公式）。
4. **「轮询回合制」词条去留**：CONTEXT.md 中该词条如何改（改为「先机回合制」或删除/重写）？

产出：更新 `CONTEXT.md` 战斗小节的术语（轮次/回合/时机/事件/先机），并作为后续所有 ticket 的统一词汇基线。

## Answer

（HITL grilling，用户全部确认推荐方案）

- **D1 轮次/回合**：**轮次 (Round)** = 所有存活参战单位各行动一次的一个完整循环；**回合 (Turn)** = 单个单位的一次行动机会（从「回合开始前」到「回合结束后」）。现有 `BattleResult.rounds` 语义即「轮次」，UI 文案「X回合」应改为「X轮」。
- **D2 时机/事件**：保持两层命名——**时机 (Timing)** = 轮次主时机（轮次开始前 / 回合开始前 / 回合进行中 / 回合结束后 / 轮次结束后，固定骨架）；**事件 (Event)** = 细粒度战斗事件（攻击后 / 受到伤害 / 受到治疗 / 死亡 / 召唤，可扩展、即时派发）。两者均为可订阅点。
- **D3 先机**：中文名「先机」，英文 key `initiative`（公式见 Turn.md，本票仅定名）。
- **D4 轮询回合制词条**：`CONTEXT.md` 中「轮询回合制」改写为「**先机回合制 (Initiative Turn)**：单位按先机值排序行动的回合制节奏」，并新增 轮次 / 回合 / 先机 / 时机 / 事件 五个术语。`战斗区域`→`区域/关卡` 归 Level 模块，本票不动。
