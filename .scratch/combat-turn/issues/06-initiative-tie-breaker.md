# 06 — 同先机排序规则（决策）

**Type:** grilling
**Status:** resolved
**Blocked by:** None

## Question

先机相同（或先机变动后相等）的单位行动顺序如何确定？

1. **稳定 tie-breaker**：采用「入场序」（英雄按上阵序 / 敌人按配置序 / 召唤物按召唤序）作为先机相等时的次排序键？
2. **先机变动后的重排**：战斗中 fixval 加算/减算导致排序变化时，如何重排（当前行动单位之后？按新先机全局重排？）？
3. **全序保证**：先机 + tie-breaker 是否构成严格全序（无并列），以满足确定性回放？

产出：确定性全序排序规则（先机 → tie-breaker → 稳定序），供 05/07 复用。

## Answer

（HITL grilling，用户全部确认推荐方案）

- **D1 tie-breaker**：**入场序（entry seq）**——全局单调递增序号，入场时分配：英雄按上阵序（0,1,2）→ 敌人按配置序 → 召唤物按召唤序依次续号；**升序 = 先入场先动**。
- **D2 先机变动重排**：只对「本轮未行动区间」按新先机重排；已行动单位本轮锁定、不插队，其新先机在下一轮进入未行动区时生效（与 05-D2 一致）。
- **D3 全序保证**：**严格全序**——排序键 `(先机 降序, 入场序 升序)`，入场序唯一 → 无并列 → 遍历序完全确定（满足 03 确定性）。
