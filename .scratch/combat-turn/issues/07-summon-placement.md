# 07 — 召唤物入场排位（决策）

**Type:** grilling
**Status:** resolved
**Blocked by:** 06

## Question

召唤物「立即参战」的精确排位如何定义？

1. **排位方式**：
   - **A)** 进入本回合待参战队列后按先机正常排位（召唤物先机 = 100 + 0 + fixval，通常靠后）；
   - **B)** 插到当前行动单位之后（紧接召唤者行动）。
2. **本回合行动机会**：若召唤发生在本回合较晚时，召唤物本回合是否还有行动机会（取决于其先机是否排到本轮剩余区间）？
3. **先机值来源**：确认召唤物其余值全为 0、仅创建时技能传入 `fixval`（Turn.md 已定），与 06 的 tie-breaker 如何衔接？

产出：召唤入场的完整规则（排位 + 本回合行动机会 + 与排序规则的关系）。

## Answer

（HITL grilling，Q1/Q2 确认推荐，Q3 用户修订）

- **D1 排位方式**：选 **A** —— 进入本轮「未行动区」按先机正常排位（不插队）；「立即参战」= 本轮即参与排序并行动。
- **D2 本回合行动机会**：召唤物**本轮即有机会行动**——进入本轮「未行动区」，该区清空前不进入下一轮，故召唤物必定在本轮剩余区间按先机排位行动一次（除非战斗先结束或被先击杀）。
- **D3 先机值来源**（用户修订）：召唤物先机**不属于「战前初始先机计算」批次**，召唤时单独计算；公式中 `agility` 项**按 0 处理（不使用其实际敏捷）**，故 先机 = `100 + fixval`（`fixval` 由召唤技能传入，clamp 0–100）。召唤物**其余面板属性以被召唤实体单位的真实配置为准**（其真实敏捷照常参与面板/派生计算，仅不参与先机）。入场序按召唤发生顺序续号，作 06 的 tie-breaker。
