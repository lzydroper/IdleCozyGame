# 经验道具与升级消耗设计

Status: resolved
Type: grilling
Blocked by:

## Question

设计英雄升级消耗经验道具的方案（已确认方向：升级消耗经验道具，不再无消耗直升）：

1. 经验道具分档：如「基础经验手册 / 高级经验手册」等，各档提供多少经验值（与 `COMBAT_CONFIG.expPerLevel` 的换算关系）。
2. 获取来源：探险掉落 / 梦境事件 / 工坊合成 / 商店——至少定一个主来源。
3. 升级按钮交互：一次消耗道具升一级，还是按持有道具可连续升级？消耗后经验溢出如何处理。
4. 与战斗经验的关系：ADR-0003「经验仅来自战斗」是否保留（建议：战斗经验照旧入账，经验道具是额外的主动升级途径）；升级仍发天赋点（`applyHeroExp` 逻辑复用）。
5. 物品注册：新增物品进 `data/items/`（category、sprite/icon 配置、描述），与 03 图标系统兼容。

产出：设计决策 + 数据配置草案 + 实施要点（指向 HeroDetailModal 升级按钮与 GameContext/state 改动）。

## Answer：经验道具与升级消耗设计决策（2026-08-07，HITL 与用户确认）

### D1. 经验道具（单档）
- 新物品 `exp_tome`「经验手册」，category `'item'`，描述：『记载战斗心得的战术手册，为英雄提供 100 点经验。』
- 经验值 = **100 exp**（与 `COMBAT_CONFIG.expPerLevel` 一致，Lv.1→2 正好一级）。
- 数据驱动：扩展 `ItemMeta.useEffect` 增加 `heroExp?: number` 字段（`exp_tome: { heroExp: 100 }`），经验值随物品配置走，与 ADR-0014/0015 一致。
- 图标：实施时先 Lucide 回退（如 BookOpen/ScrollText 类），sprite 待补（虚线框暴露）；若 materials/seeds 表有空闲格则补配。

### D2. 获取来源
- **战斗/探险掉落**：探险与战斗结算的掉落池加入经验手册（实施时挂接掉落表）。
- **梦境不掉落现实物品**：梦境事件保持世界观一致性（只掉梦境碎片/精神类物品），不加入手册。
- 不做工坊合成（用户未选）。

### D3. 升级交互
- 【升级】按钮：**一次消耗 1 本经验手册** → 英雄 +100 经验（`applyHeroExp` 复用，升级仍发天赋点；经验溢出自动累计）。
- 升级按钮**上方新增【批量升级】按钮**：逻辑与背包/工坊批量一致——弹出批量界面 + 滑条选择消耗数量（1..持有数），**实时预览**：消耗 N 本 → 获得 N×100 经验 → 可升至 Lv.X、剩余经验 Y、新增天赋点 Z。
- 持有 0 本时升级按钮禁用并提示来源。

### D4. 与战斗经验的关系
- ADR-0003「经验仅来自战斗」**保留为主途径**，经验手册为**额外主动升级途径**（用户已确认方向）；两者进同一条经验条，天赋点发放逻辑不变。此为 ADR-0003 的补充说明，实施时可在 ADR 追加一行。

### 实施要点（毕业为 15 号 ticket）
- 物品注册（props.ts / 新文件）+ ItemMeta 类型扩展。
- GameContext 新增批量消耗 action。
- HeroDetailModal 升级/批量升级 UI（滑条 + 预览弹窗，复用背包/工坊批量弹窗交互范式）。
- 探险/战斗掉落表接入。
