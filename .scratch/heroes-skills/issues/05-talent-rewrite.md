# 天赋重写语义

Type: grilling
Status: resolved

## Question

天赋如何重写英雄主动技能？多个天赋同时重写同一技能时怎么合成？能不能追加槽位外的新技能？

## Answer

- 重写 = overrides 部分 patch：
  - `overrides.priority`：顶层覆盖发动优先级（readme 第 6 条）；
  - `overrides.effects`：按**效果索引**定位部分替换（如 `{"0": {...}}` 替换第 0 个效果，未提及的效果原样保留）——现有 `AbilityRef` 的浅合并撑不起"只改部分效果"，英雄侧不用它；
  - 描述文本同样支持索引级覆盖，供预览弹窗展示重写后效果。
- 多个天赋重写同一技能：按**天赋树节点顺序**依次应用。
- 硬边界：天赋只能重写三个既有槽位的技能，**不能追加**第四个主动技（三槽是硬边界）。
- 三槽皆可重写，觉醒技不做例外。
- 天赋被动（数值随投入点数与英雄自身属性）继续走现有 modifier 通道，不在本次改动面内。

## Comments

**实现期扩展（B6）**：`TalentRewrite` 增加 `description?: string`——主描述模板整体替换。动因：效果种类被改写时（样板：flat→attack），原模板的 `{value}` 占位符失效，裸露花括号并触发 DEV 告警；整体替换后占位符照常经渲染器出实际值。
