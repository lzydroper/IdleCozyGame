# 概述

- 当玩家在线时，无论玩家是否停留在挂机界面，战斗过程都会持续进行，体验和主动战斗相近（指播放速度等）；挂机战斗会持续循环玩家当前选择的关卡，每次开始一次新的关卡挂机战斗流程扣除一次体力，每次结束战斗结算收益。
- 每次战斗流程不是恢复状态，而是创建新的战斗快照，所有状态自动恢复，无需额外处理。
- 玩家离线时挂机战斗**停止计算**，相关信息仅本地保存、云端不保存；玩家重新上线时继续流程。
- 体力的自动回复只与在线时的具体时间流动和离线后的离线时长有关，由其内部维护；外部只能获取当前体力值、请求修改当前体力值（返回是否成功），与其他系统解耦。

## 与既有决策的关系

本语义**反转 ADR-0002 的"确认式离线挂机（离线推进）"**：离线不再推进战斗，改为暂停。需另立 ADR 记录该变更及受影响面（`settleIdleUpdate` 离线分支、`lastOfflineReport.idleCombat`、`battleDurationSeconds` 封顶等）。
