# 概述

希望对 UI 界面进行重新调整和编排：

- "挂机战斗"更名为"战斗"。
- 区域选择：点击后出现选择器，罗列按readme规则的区域信息，点击任意区域后出现弹窗，显示区域信息，有确认和取消按钮，其中确认按钮仅在区域已解锁时可用，区域未解锁时需罗列被锁住的原因和对应原因实现情况；该组件应能在荒野探索、战斗、远征中都可复用
- 独立的、统一的、可复用的战斗页面；战斗页面只有战斗信息，类似独立的招募页面。
- 关卡浏览：参考readme描述
- 可以选择某个关卡进入挂机战斗，出现简略（可能只显示三条）的战斗信息区域。
- 由于是对UI界面的调整，必要时需要使用prototype技能

## 退出按钮范围

- **仅独立的战斗页面**提供"退出"按钮，退出按战斗失败结算。
- **其余系统（如探索）只读战斗结果**，不在战斗页面内提供退出按钮；探索的撤离是探索侧操作，无损。
