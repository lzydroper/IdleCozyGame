1. 英雄的三个槽位用于显示三个主动技能，分别为1技能、2技能和觉醒技能；

2. 技能槽位中的技能无论是否解锁，都支持点击出现弹窗以预览效果和解锁条件；

3. 技能的解锁条件和数值影响有等级、觉醒、星级；

4. 约定装备只会提供被动技能，装备的被动技能的数值只和装备自身的强化等级有关，装备的被动技能数据应保存在装备数据自身或是对应套装数据中；

5. 约定天赋系统会提供被动技能，也可能会重写英雄的主动技能，天赋的被动技能的数值只和投入天赋点数和英雄自身属性有关，天赋重写的主动技能仅改变部分效果，数值理论和正常技能相同，天赋的技能的数据应同时支持引用AbilityId和重写；
6. 天赋对主动技能的重写包括发动优先级；
