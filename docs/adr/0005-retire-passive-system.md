# 退役旧幸存者被动系统（passives）

Status: accepted

现有 9 位幸存者全部依赖 `passives` 静态加成（工坊能耗 -20%、作物生长 +25%、探索消耗 -15%、拾荒间隔 -25% 等）提供差异化，其中生产类加成与"机器生产无需指派"的新产线模型冲突（见 ADR-0004）。决策：**旧 `passives` 系统整体退役** —— 生产加成全面废除，探索/生存类被动也不再保留；角色的差异化完全交给新系统承担（职阶、天赋树、羁绊、装备、觉醒）。产线、种植等生产环节的数值改为全局平衡，不再依赖个别角色。

## Considered Options

- **部分保留**（仅废生产被动、留探索/生存被动）：会留下一条边界模糊的旧系统（哪些被动"属于生产"难以界定），且老角色仍依赖旧机制。否决。
- **全部保留**（新系统叠加旧系统）：差异化最强但维护两套加成体系，冲突面最大。否决。
- **整体退役**：架构最干净，角色价值单一地由战斗养成体系承担。采纳。

## Consequences

- 现有 9 位幸存者的 `role`（6 类）迁移到 3 个新职阶（守护者/进攻者/协奏者），迁移映射为一次性数据改造。
- 手动探索（双模式之一）的消耗平衡改为全局数值，不再有角色层面的减免。
- `passiveModifiers` 体系随之废弃，相关条件修饰（rescued/assigned）不再使用。
