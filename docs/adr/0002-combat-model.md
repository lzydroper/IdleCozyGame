# 战斗模型：三人轮询回合制自动战斗 + 探索战斗汇合

Status: accepted

游戏需要"养成打怪"循环。决策：

- 战斗采用**三人小队轮询回合制**（无阵型），消耗**独立体力**（随时间恢复），并入荒野页签、与手动卡牌探索**并存双模式**。
- **探索战斗汇合**：手动探索中遭遇战斗时，进入与自动战斗**同一战斗场景**，沿用当前上阵三人小队；胜利继续探索，战败则探索终止（**战利品保留**），小队全员进入重伤状态（见 ADR-0006）。
- **确认式离线挂机**：战斗挂机需玩家在某区域主动点"开始挂机"后才在离线期间推进，可随时停止；体力耗尽自动停止，停止后体力保留。
- 内容组织为**线性递进区域 + 每区关底 BOSS**，掉落物包括材料、装备与灵魂残响。
- **羁绊**（特定组合上阵触发数值加成）与**阵营**（六阵营：奥术/机械/梦魇/英灵/星界/魂印）驱动队伍差异化。

## Considered Options

- **战斗形态**：卡牌抉择战斗 / 回合制手动 / 远征定时结算 —— 均偏离 Melvor 式挂机体验，否决；选自动挂机。
- **资源消耗**：共享 HP/食物会与探索互相挤兑，否决；选独立体力。
- **挂靠位置**：新页签可行但增加导航负担，选并入荒野页签。
- **探索与战斗完全隔离**（初版设想）：探索中触发战斗会割裂体验，修订为汇合共用战斗场景。
- **离线自动结算**（初版设想）：无确认地一直离线计算造成意外消耗与负担，修订为玩家确认式挂机开关。
- **区域组织**：无 BOSS 纯数值递进缺乏目标感、多路线开放开发过重，选线性区域 + BOSS。

## Consequences

- 战斗与探索共享页签但资源隔离（探索耗魔能/食物，战斗耗体力）。
- 离线结算扩展现有 lastTick 机制，且仅在玩家开启挂机的区域与时段生效。
- 羁绊/阵营成为队伍构筑的核心策略层，与装备/职阶共同决定队伍强度。
- 战斗失败不损战利品，风险由英雄重伤状态承担（见 ADR-0006）。
