# 逐动作动态回合战斗与单场跳过机制

Status: accepted

战斗不再瞬间完成，改为基于时间间隔的逐动作动态播放，同时在非挂机战斗中提供单场 Skip 功能。

## Decision

1. **动态播放**：非挂机战斗按配置时间间隔（如 1000ms）逐动作播放攻击、技能与血条扣减。
2. **循环倍速**：界面提供倍速按钮，支持在 `1x -> 2x -> 4x` 倍速间循环切换。
3. **单场 Skip**：主动探索/挑战类单场战斗提供“跳过”按钮，点击瞬间结算该场战斗；离线挂机维持后台 Tick 结算，不提供 skip 按钮。
4. **胜后状态恢复**：战斗胜利后英雄自动恢复满血，下一场战斗重新满血开始。
