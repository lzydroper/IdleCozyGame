# 产线模型：配方队列 + 设施等级扩容

Status: accepted

产线在现有 smelter/assembler 双设施基础上改造：每个设施维护一条 **FIFO 配方队列**（多配方顺序执行），**队列长度随设施等级提升**，**设施数量靠扩建/解锁增加**（多设施并行）。产线**纯机器自动运转，无需指派人员** —— 现有"指派幸存者加速产线"机制废除。

## Considered Options

- **流水线链式喂料**（上游产物自动进下游）：形成供应链依赖，实现成本中等。否决：本改造阶段优先把战斗/英雄系统做透，产线保持管理向。
- **网格布局**（类 Factorio：摆放设施、连接输送、空间约束）：复杂度最高、与放置经营基调冲突。明确否决。
- **人工指派产线**：与"英雄投入战斗"的新重心冲突，且旧被动系统已退役（见 ADR-0005）。选纯自动。

## Consequences

- 产线成为纯粹的"挂机生产力来源"，与战斗/英雄系统解耦。
- 队列 UI 与多设施并行需要新的设施管理界面（当前为单配方选择）。
