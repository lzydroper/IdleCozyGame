# 恒定 3 人小队上阵选择 Modal 与后勤/已上阵过滤规制

Status: accepted

定义 3 人小队上阵交互 Modal 及后勤/战斗英雄冲突规制。

## Decision

1. **恒定 3 人小队**：小队槽位数量恒定为 3 个（可通过全局变量配置扩展）。
2. **上阵选择 Modal 过滤规则**：
   - 点击小队槽位弹出英雄选择 Modal。
   - 处于**后勤驻守中**或**其他槽位已上阵**的英雄：头像变为**灰色**，**默认排序在列表最末端**，点击**无反应、无提示**。
   - 处于当前点击槽位的英雄可以被勾选/取消勾选，包含【确认】与【取消】关闭按钮。
