# 废除全局生命值（HP）：重伤与梦境封锁机制

Status: accepted

玩家角色的全局 `hp/maxHP`（PlayerStats）体系废除，生存风险完全由英雄承担。决策：

- 英雄各自拥有**独立 HP**；战斗失败（小队全灭）后全员进入**重伤**状态 —— **禁止上阵**，需使用恢复道具治愈。恢复道具为**改造后的纳米修复剂（nanite_injector）**（工坊制造），不再承担原"恢复玩家 HP"用途。
- **梦魇泄露**改为出战当前小队防御：防御失败 → 小队全员重伤 + **梦境封锁**（梦境探索禁用，持续时长可配置）。现有**炮塔**保留为泄露战斗的**辅助战力**（开战时炮塔先输出一轮再进入战斗）。
- 手动探索保留**魔能/食物消耗**，仅移除 HP 相关惩罚。
- **战利品永不因战斗失败丢失**：原"探索死亡清空临时背囊"惩罚废除。

## Considered Options

- **探索失败丢失战利品**（原机制）：与放置经营"舒适挂机"基调冲突，否决。
- **探索失败额外扣资源**：惩罚过重且无角色层面反馈，否决。
- **炮塔纯被动防御**（原机制）：无法体现英雄养成与战斗，改为泄露战斗辅助。
- **无失败代价**：战斗缺乏风险感，否决；选重伤（恢复道具形成明确闭环）。

## Consequences

- `PlayerStats` 移除 `hp/maxHP`；`stat_cost_hp` 类消耗与相关被动随之移除（被动体系已整体退役，见 ADR-0005）。
- `nanite_injector` 语义从"恢复玩家 HP"改为"治愈英雄重伤"。
- `nightmareConfig` 炮塔数值保留，语义变为泄露战斗的辅助输出。
- 新增"梦境封锁"计时状态，需要可配置的持续时长与解除逻辑。
