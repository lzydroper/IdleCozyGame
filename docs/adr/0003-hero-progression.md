# 英雄养成模型：经验、装备、天赋、升星与觉醒

Status: accepted

英雄养成由五条线组成，全部面向战斗（等级经验**仅来自战斗**，生产不产出经验）：

- **等级**：击杀获得经验，升级解锁天赋点与被动上限。
- **装备**：武器/防具/饰品 3 槽，**无品质**、按**系列套装**组织；**强化**仅加属性、上限 +30，同系列穿戴强化达 +10/+20/+30 触发套装特效；+30 后**锻造为神话装备**（属性加强、更名、附带系列共有词条，强化等级保留）。装备获取分层：工坊合成特定系列 → 图纸解锁合成 → 梦境探险掉落 → 最强系列仅击败区域 BOSS 获得。
- **天赋树**：按**职阶**组织（守护者/进攻者/协奏者），公共主干 + 每英雄专属节点，各英雄天赋树独立。
- **升星**：消耗该英雄灵魂碎片（或通用共鸣碎片）提升星级。
- **觉醒**：满星英雄的二次进化，消耗**奥术星体**，改变外观、强化被动、解锁专属战斗技能，是终局养成目标。

## Considered Options

- **经验来源**：生产/探索也产经验会让角色定位模糊，否决；仅战斗，职责纯粹。
- **装备品质**：品质分层与系列套装叠加过重；选无品质 + 套装 + 强化，深度由"套装特效 + 神话锻造"承担。
- **天赋树结构**：纯通用树抹平角色差异、纯专属树工作量过大；选职阶主干 + 专属节点。
- **觉醒时机**：与升星平行会稀释终局目标；选"满星后"作为二次进化，形成 等级→装备→升星→觉醒 的单向终局曲线。

## Consequences

- 装备强化资源、"奥术星体"与各系列套装的获取途径需配套数值设计（当前未定，可配置）。
- 觉醒的"专属战斗技能"是新战斗层，需与轮询回合制战斗结算联动。
- **补充（15 号）**：经验手册（`exp_tome`）为额外主动升级途径——战斗/探险掉落获得，消耗 1 本 = 100 经验（`ITEMS_CONFIG` 配置），与战斗经验同一条经验条，升级仍发天赋点。
