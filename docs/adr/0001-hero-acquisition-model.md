# 英雄获取模型：统一召唤池

Status: accepted

游戏要引入 Melvor 式的英雄抽取，而现有 9 位幸存者走固定剧情链（梦境共鸣 → 现实救援）解锁。决策：所有角色（现有幸存者 + 未来新增）进入**同一个召唤池**，救援链**保留为免费获取途径**（共鸣满 100% 直接获得，不消耗货币）；召唤池**无稀有度分级**（单概率池），以**软保底**作为唯一概率保护（阈值可配置测试）。重复获得同一英雄时转化为该英雄的**灵魂碎片**（专属），另有通用**共鸣碎片**。

## Considered Options

- **共存分层**（幸存者与英雄池分离）：叙事最清晰，但养成系统要维护两套角色体系。否决：改造目标是统一养成。
- **全量 gacha**（删除救援链）：系统最简，但割裂既有梦境/荒野叙事。否决：叙事是游戏核心风味。
- **稀有度分级**（N/R/SR/SSR/UR 或三档）：常见 gacha 分层，但会强制 9 位老幸存者分高下、破坏"无高低"的角色关系。否决。
- **硬保底**：简单但僵硬。选软保底：数值可配置，便于上线后调参。

## Consequences

- 引入新货币"灵魂残响"，与现有魔能/材料经济隔离。
- 同一英雄有两条获取途径（救援免费 / 召唤付费），重复获取自然转化为养成材料，闭环成立。
- 无稀有度意味着所有英雄获取概率相同，角色差异完全由养成与羁绊承担。
- 开局**固定赠送初始英雄**（诺娃，叙事上为第一位同伴）且入池可重复抽取，保证新手无需召唤即可进行荒野探索。
